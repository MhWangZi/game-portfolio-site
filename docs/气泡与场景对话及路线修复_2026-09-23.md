# 气泡、可移动对话窗与房间路线修复

日期：2026-09-23

- 助手气泡根据角色实际屏幕矩形定位，四边夹限；上方空间不足时放到下方，尾巴指向助手。兼容窗口缩放、音乐及游戏停靠状态。
- 场景对话窗左上角点阵手柄可拖动，方向键微调，Shift加速，Home或回转箭头归位。位置按可移动范围比例独立保存在mw-scene-dialogue-position-v1，刷新和新事件沿用；拖动期间不自动关闭观察。
- 原档案角→旧放映间为单向错误连接：放映间仅有回实验间的门。保留实验间↔旧放映间，档案角侧门改为不可通行的观察事件；移除相应转场，楼层图从配置自动更新。
- 新事件archive-closed-door：首次描述把手弹回，助手说明经走廊与实验间前往；重复提醒门仍打不开。不发纪念物，不改解谜顺序。
- 验证：19项回归测试、TypeScript和生产构建；实际拖动至左侧及顶部、375像素窄屏、场景文字拖动、刷新保留、键盘归位和侧门反馈。
- 所有room类型的连接均检查反向可通行门，防止再出现进出目标不一致。
