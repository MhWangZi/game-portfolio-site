## 本轮发现与处理

1. 旧逻辑测试仍断言新增热点之前的事件数量，已更新为当前配置数量。
2. 旧版作品集首页的浏览器测试无法用于现今的游戏首页，已替换为当前玩家流程测试，保留管理终端入口验证。
3. 公开站点上内嵌游戏的启动按钮曾先于加载脚本显示。网络较慢时，玩家迅速点击会没有反应并停在封面。两款游戏的按钮现默认禁用，脚本绑定点击处理后才启用；本地和公开站点均复验。
4. 首次在线下载较慢。本次链路中，CLICKDOWN约120秒进入可玩状态，切盘后的万众瞩目也约120秒；万众瞩目独立进入约108秒。加载进度持续推进，最终成功。这是体验风险，不应把可访问等同于快速可玩。

## 仍需真人验收的部分

- 音乐、雨声、音效的听感、响度与叙事节奏；自动化只能确认文件可解码、控件可操作和状态变化。
- 低性能设备、非Chrome浏览器和不同地区网络下的帧率与首次下载时间。
- 77条热点的逐个文案与视觉细节；本轮验证了热点配置、重点事件及十个房间的主要路径，没有逐句人工审校。

## 复验命令

在项目根目录依次执行：

```powershell
npm run build
npm run lint
node --test scripts/*.test.mjs
npx playwright test
node scripts/public-game-smoke.mjs
$env:PUBLIC_GAME_DEEP='1'; node scripts/public-game-smoke.mjs
```

最后一条会从公开站点下载两款完整游戏，耗时取决于网络。录像快速入口仅在本机预览的`?reel-test=1`下可见，真实录像带拿取与插入路径在`?review=1`的本地验收入口中测试。
